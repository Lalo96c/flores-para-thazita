# Flores amarillas 🌻

Abre esta carpeta en Visual Studio Code. Ejecuta `python app.py` desde su terminal y visita http://localhost:8000. Requiere Python 3, sin librerías adicionales. Detén el servidor con Ctrl+C.

Python sirve la página; HTML y CSS muestran el diseño, y JavaScript activa la animación en el navegador. También puedes abrir `dist/index.html` directamente para ver el regalo sin servidor.

Personaliza la dedicatoria en `dist/index.html` y el mensaje final en `dist/garden.js`. El dibujo del girasol utiliza el emoji del sistema, por lo que puede variar entre dispositivos. La página respeta la preferencia de movimiento reducido.

El servidor se limita a tu computadora. Para enviarla por enlace será necesario alojar la página en un servicio web.
